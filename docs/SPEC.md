# 诊所耗材补货计划

社区诊所库管在日切后分配低值耗材采购预算。样例是合成的门诊领退用、诊室库存计时及整箱询价。包含领用迟到、整箱与散件换算、错误修订、缺货截尾、零用量和短历史。容量每单位代表十元采购预算，默认 480 元。金额进入算法后全程以整数分表示。

同库同品项按日结算可用历史。已开门无领用是观测零，无库存全日关闭视为缺失。部分断供先按有效时段反推，每日回补幅度受过去正常日的中位数限制。七日预测优先使用可见同星期中位数，稀疏时用 Syntetos–Boylan 修正的 Croston 模型。训练只用预测前可见行；断供回补量可以进入训练，但任何包含断供日（非完整营业日）的周都不是完整回测周，不能用于核量安全库存。安全件数来自非重叠的七日残差窗及有限样本分位数，完整回测周不足时交由人工审查。拆箱规格、保质期周转、冷位和整箱金额都参与约束。

### 逐周时点回测

- 重算补货时，安全库存由逐周回测核准：每个回测周只用周初已经过账的领用流水和当时可见的库存记录重建七日预测。
- 迟到的领退用记录（含晚到修订）按凭证修订规则更正最终结算用量，但不会改变它过账之前任何一周的周初预测；回测不允许偷看未来。
- 周初预测与最终结算分开留证：残差以「周初预测」对「最终结算用量」计算，迟到修订通过结算端进入残差，而不是通过预测端。
- 整日关闭、库存记录缺失或含断供日的周不构成完整回测周；只有完整周的残差进入安全库存分位数。
- 能用于核量的完整周数不足时，安全库存留待人工核量；但关键耗材的现货加在途若撑不过预测的七天，仍给出补缺口的应急整箱建议（受冷位与保质期约束）。
- 采购预算不足时按层分配：先补关键耗材的预计缺口（含应急整箱），再补一般耗材的预计缺口，最后才动用经验证的安全库存；同层内按每元边际短缺减少量排序。

消耗复盘仅使用已结历史，计算滚动回测的模型和周周期基线 MAE；同商品、同仓点都保留独立试算。工作台柱图为当前各耗材的预测绝对偏差均值，单位为件。该项目进行库存与单据协作，样例不含患者信息。

## 决策证据

工作台提供逐凭证出入与仓点守恒、不同最低营业暴露下的断供修复影响、真实周度留出比较和整箱预算上界试算。预算试算用整数状态枚举满足冷位与保质周转的多商品组合，在「关键预计缺口 → 一般预计缺口 → 经验证安全库存」的分层目标下最大化覆盖，状态过大时明确切回边际贪心。留出误差仅使用完整营业日的已记账观察值。历史窗按非重叠块计数，中途缺档、整日关闭或含断供日的周都不会用被修复的数量作验证真值。逐周时点回放（`weekly_safety_replay`）对每个回测周重建周初可见流水下的预测，并把迟到修订隔离到结算端；周窗误差差值区间是回顾性近似，样本不足时生产证据不赋予结论。关键耗材在安全库存未核量时仍保留应急整箱证据，未核量的一般耗材不产生采购。
